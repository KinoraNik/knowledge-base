### 3.2 Частые вопросы (FAQ)
Вопрос: Как добавить новый товар в систему?

Ответ:

- Войдите в систему под своей учётной записью.

- Перейдите в раздел «Товары» (левое меню).

- Нажмите кнопку «Добавить товар» (в правом верхнем углу).

- Заполните обязательные поля: название, артикул, единица измерения, цена.

- Нажмите «Сохранить».

**Важно**: если товар уже есть в системе, но вы не видите его в списке, проверьте фильтры (возможно, стоит фильтр «Только активные»)

*Совет: чтобы не заполнять карточку каждый раз вручную, используйте импорт из Excel (раздел «Товары» → «Импорт»).*
